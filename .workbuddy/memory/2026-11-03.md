### 实测（seed 42 / 同 split / 同负样本 / 指标函数全部 import 自 relaware）

| 配置 | test MRR | hard MRR | OOD | 金标分离度 | 写回 | 错误率 |
|---|---:|---:|---:|---:|---:|---:|
| random（基线） | 0.3609 | 0.6938 | 0.8611 | **0.3814** | 118 | 88.1% |
| mini·table·冻结 | **0.3687** | **0.7777** | 0.9167 | **0.7664** | 183 | **81.1%** |
| mini·table·微调3步 | 0.3556 | 0.7370 | 0.8611 | 0.7644 | 166 | 84.1% |
| mini·table·微调10步 | 0.3370 | 0.7242 | 0.8264 | 0.4976 | 95 | 94.5% |
| mini·dense·微调 | 0.3668 | 0.7411 | **0.9861** | 0.5341 | 96 | 89.1% |
| charngram | 0.3025 | 0.6649 | 0.8403 | 0.4151 | 98 | 94.5% |

覆盖率 331/335 = 98.8%（OOV：游动/v、筑造/v、认知/v、声呐器官/n）。

### 五条结论

1. **`--init random` 逐位复现基线**（0.3609 / 0.6938 / 118 行 / best epoch 13）。
   为此复制了 relaware main 的训练段（含 `init_attention` + `init_loss` 两次前向，
   它们在 `train()` 模式下消耗 dropout 随机数，删掉就复现不了）
2. **基线分离度只有 0.3814** —— 模型给错条（0.8864）的分比对的（0.8641）还高。
   这是做金标才量出来的，任务书没提。mini 冻结把它推到 0.7664（两倍），
   charngram 只到 0.4151 ⇒ **收益来自语义内容，不是「不再共享随机向量」**
3. **写回错误率只从 88.1% 降到 81.1%**：过滤近似均匀（对条留 77%、错条留 55%），
   96 vs 13 的底数悬殊，砍一半错条比例仍是 81%。**问题在目标函数不在特征**
4. **`猫 is_a 人` 不降反升**（0.9915→0.9999），`鱼 is_a 无脊椎动物` 0.8327→0.4849。
   嵌入能修「属性差异大的错条」，修不了「层级互斥」。任务书「人与猫在预训练空间
   距离远」的假设不成立（都是高频名词，余弦 0.4~0.5）
5. **微调步数越多越糟**：冻结 0.3687 / 微调 3 步 0.3556 / 微调 10 步 0.3370。
   不是「能不能微调」，是「拽多久」

### 三处静默失败（都是跑了才发现）

- `--freeze-epochs 10` 与不冻**逐位相同**：`--freeze-gat-epochs` 会顺带冻住
  `node_embedding`（它在 `model.gat` 里），GAT 解冻那一刻把嵌入也解开 ⇒ 两个开关
  变成一个。改成每 epoch 开头统一重算，且嵌入赋值写在 GAT 赋值之后
- `charngram` 首轮覆盖率 0%、test MRR 0.0128：加载器是空的，OOV 回退还是 `zero`
  ⇒ 全零向量。必须强制 `--oov-mode charngram`。**不报错**
- dense 首轮 MRR 0.3402：输入没重标范数，`h0` 行范数 0.874（应为 0.5657）。
  加上 `rescale_rows` 后 0.3668、OOD 0.9861 ⇒ 那 0.027 全是尺度效应

### 口径纠错

- **金标分离度不能混组算**：写回条是按置信度 top-3 挑的，对照组（未见真边，均分
  0.54）混进来会把分离度算成 0.28。首轮就是这么错的，已改成写回组内比较
- **`load_relation_target_pos` 从 closure 统计会多放行**：`relations` 里
  `typically_has` 目标是 146 n / 3 a（a 占 2.0% < 5% 门槛），`closure` 里是
  208 n / 18 a（8.0%）⇒ a 被放行。118 条里 31 条 `typically_has → 形容词` 由此而来。
  **这是上一轮的设计缺陷，本轮没改**（改了会让既有 118 行失效），已记进文档 §12 与 §7
- **写回行数不是质量指标**：冻结组写 183 行（比基线多 55%）错误率最低；微调 10 步
  写 95 行（比基线少 20%）错误率最高。上一轮把「写入量降到 50~80」当验收准则是错的

### 接线验证

把 `mini_vectors.txt` 当外部文件喂 `--init file --vectors`，结果与 `--init mini`
